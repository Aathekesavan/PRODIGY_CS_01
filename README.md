### Advanced Caesar Cipher Cryptography System

METACIPHER is a modern cyber-security themed web and desktop application suite built as part of my Cyber Security Internship at Prodigy InfoTech.

The project transforms the traditional Caesar Cipher into a professional cryptography dashboard featuring real-time encryption, brute-force analysis, security visualization, analytics, and an interactive cipher wheel.

---

## 🚀 Features

### Core Features

* Caesar Cipher Encryption
* Caesar Cipher Decryption
* Real-Time Processing
* Adjustable Shift Key
* Copy-to-Clipboard Support

### Advanced Features

* Interactive Cipher Wheel (Dynamic SVG Rotation)
* Brute Force Analysis Matrix
* Encryption History Logs (Stored in Local Storage)
* Security Status Dashboard
* Real-Time Analytics
* Key Strength Indicator (Entropy Score)
* Export Operations (TXT / JSON Auditing)
* Keyboard Shortcuts

### Analytics Dashboard

* Character Count
* Word Count
* Shift Value Tracking
* Processing Speed
* Security Score Visualization

## ⚙️ Running the Applications

### 🌐 Option A: Open the Web Platform (Recommended)
You can open the web app instantly. Simply double-click [`index.html`](file:///d:/PRODIGY_CS_01/index.html) in any browser, or serve it locally:
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your web browser.

### 🖥️ Option B: Start the Desktop GUI
1. Install Python requirements:
   ```bash
   pip install -r requirements.txt
   ```
2. Start the app:
   ```bash
   python caesar_cipher_gui.py
   ```

### 📟 Option C: Start the Terminal CLI
```bash
python caesar_cipher.py
```

### 🧪 Running Verification Tests
```bash
python test_caesar_cipher.py
```
